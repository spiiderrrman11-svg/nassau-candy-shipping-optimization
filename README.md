# Nassau Candy Distributor ML Project

## Objective
Analyse shipping duration, sales, costs, and gross profit to
support shipping-efficiency and factory-reallocation decisions.

## Work completed
- Loaded and inspected the dataset
- Checked missing values and data types
- Created a Shipping Days feature
- Analysed shipping modes, regions, and divisions
- Visualised sales and profitability
- Trained an initial Random Forest regression model
- Evaluated predictions against a baseline
- Summarised business KPIs

## Important limitations
- The current dataset does not contain an explicit factory assignment.
- It does not establish actual delivery time or shipping expense.
- Factory reallocation requires factory assignments, capacity,
  product eligibility, and factory-to-destination shipping costs.
- Model performance must be validated before operational use.

## Technologies
Python, pandas, scikit-learn, Matplotlib, Seaborn, Google Colab
